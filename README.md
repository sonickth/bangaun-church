# 반가운교회 홈페이지 운영 가이드

iscs.or.kr(일산충신교회)의 메뉴 구조·디자인 톤을 참고해 만든 다중 페이지 사이트입니다.
**회원가입/로그인, 방문자가 직접 글을 쓰는 게시판**은 실제 서버·데이터베이스가 필요해
이번 버전에는 포함하지 않았습니다 (하단 6번 참고). 그 외에는 지금 그대로 실제 운영이 가능합니다.

## 파일 구성

```
index.html      홈
about.html      교회소개 (인사말·연혁·교역자)
service.html    예배안내 (예배시간·온라인예배)
vision.html     목회비전 (4대 사역·소그룹)
missions.html   선교 (국내·해외 후원선교지)
news.html       나눔터 (공지사항·선교지소식, 읽기 전용)
contact.html    오시는 길 (지도·신청/문의 폼)
assets/style.css  공통 디자인
assets/site.js    공통 기능(메뉴 열고닫기 등)
```
7개 HTML 파일과 assets 폴더를 **모두 같은 위치**에 함께 올려야 정상 작동합니다.

---

## 1. 기본 정보 입력 (필수)

각 HTML 파일에서 아래 표시를 Ctrl+F로 찾아 실제 정보로 바꿔주세요.
(같은 표시가 여러 파일에 반복되어 있으니, 파일마다 확인이 필요합니다.)

| 찾을 표시 | 바꿀 내용 | 있는 파일 |
|---|---|---|
| `[[ADDRESS]]` | 교회 도로명 주소 | 모든 페이지 하단 + contact.html 지도 |
| `[[PHONE]]` | 대표 전화번호 | 모든 페이지 하단 |
| `[[EMAIL]]` | 문의 받을 이메일 | 모든 페이지 하단 + contact.html 폼 |
| `[[YOUTUBE_ID]]` | 유튜브 영상/라이브 ID | service.html |
| `[[YOUTUBE_CHANNEL_URL]]` | 유튜브 채널 주소 | service.html |
| `○○○`, `○○` | 목사님/선교사님 성함, 지명 등 | about.html, missions.html |

지도는 API 키 없이 바로 작동합니다. `[[ADDRESS]]`만 실제 주소로 바꾸면 됩니다.

---

## 2. 나눔터(공지사항) 올리는 방법

`news.html` 하단의 `NOTICES` 배열을 수정합니다.

```js
const NOTICES = [
  { tag: "공지", title: "가을 심방 일정 안내", date: "2026.09.02",
    body: "본문 내용을 여기에 적습니다." },
  // 새 글은 배열 맨 위에 추가하면 최신순으로 표시됩니다.
];
```
- `tag`는 화면 상단 탭(공지/행사/선교지소식)과 이름이 같아야 필터링됩니다.
- `index.html`에도 최근 소식 3개를 보여주는 같은 형식의 배열이 있어 함께 관리하시면 됩니다.

## 3. 선교지 목록 수정

`missions.html` 하단의 `MISSIONS` 배열에서 `domestic`(국내)/`overseas`(해외) 목록을 수정합니다.

---

## 4. 신청/문의/기도요청 접수 방식

기본값은 **이메일 전송(mailto)** 방식입니다. 방문자가 폼을 작성하고 [보내기]를 누르면
자신의 이메일 프로그램(또는 앱)이 열리며 `[[EMAIL]]`로 보낼 수 있게 됩니다.
설정은 간단하지만, 방문자 기기에 이메일 앱이 없으면 작동하지 않을 수 있습니다.

**더 안정적으로 운영하려면 (권장, 무료):**
1. [formspree.io](https://formspree.io) 무료 가입 (월 50건까지 무료)
2. 새 폼 생성 후 발급되는 주소 복사 (예: `https://formspree.io/f/abcd1234`)
3. `contact.html`에서 `<form action="mailto:[[EMAIL]]" ...>` 부분을
   `<form action="https://formspree.io/f/abcd1234" method="POST">` 로 교체
4. 제출 시 등록한 이메일로 알림이 도착하며, 스팸 방지 기능도 제공됩니다.

## 5. 실제 배포(호스팅) 방법 — 도메인 없이 무료로 시작

### 방법 A. GitHub Pages (완전 무료, 기술 지식 약간 필요)
1. github.com 가입 → 새 저장소(Repository) 생성
2. 7개 HTML 파일과 `assets` 폴더를 **폴더 구조 그대로** 업로드
3. 저장소 [Settings] → [Pages] → Branch를 `main`으로 설정 후 저장
4. 몇 분 후 `https://아이디.github.io/저장소이름` 주소로 접속 가능

### 방법 B. 국내 호스팅 (관리가 더 쉬움, 유료)
- 카페24, 가비아 등에서 호스팅 상품 구매 → FTP로 전체 폴더 업로드
- 원하는 `.com`/`.kr` 도메인도 함께 구매해 연결 가능

## 6. 회원가입/로그인/글쓰기 게시판이 꼭 필요하시다면

iscs.or.kr처럼 회원가입, 로그인, 방문자가 직접 글을 쓰는 게시판을 운영하려면
지금의 정적 파일 방식이 아니라 **서버 + 데이터베이스**가 있어야 합니다. 현실적인 방법은 두 가지입니다.

1. **워드프레스 등 CMS + 유료 호스팅**: 카페24 등에서 워드프레스 호스팅 상품을 구매하고,
   교회 게시판/회원 관리 플러그인(예: BuddyPress, Ultimate Member)을 설치하는 방식.
   월 1만 원 내외부터 시작 가능하며, 별도 개발자 도움을 받으면 지금의 디자인과
   유사하게 커스터마이징할 수 있습니다.
2. **교회 전용 홈페이지 서비스 이용**: "교회사랑넷", "하이워십" 등은 회원가입·게시판·헌금관리 등을
   이미 만들어진 형태로 제공합니다. 코드 관리 부담 없이 빠르게 시작할 수 있지만,
   지금 만든 디자인은 그대로 사용할 수 없습니다.

어느 쪽이든 원하시면, 다음 단계(예: 워드프레스 초기 세팅, 플러그인 선택)를 이어서 안내해 드릴 수 있습니다.

## 7. 이후 자주 하실 일

- 나눔터 글 추가/삭제: 2번 참고
- 선교지 목록 변경: 3번 참고
- 예배시간 변경: 각 페이지에서 "오전 11:00" 등 시간 텍스트 직접 수정
- 온라인예배: 방송 시작 전 `[[YOUTUBE_ID]]`를 그날 라이브 영상 ID로 교체 권장

궁금한 점이 있으면 언제든 다시 문의해 주세요.
